✅ Pedido Registrado

El pedido ha sido creado en el sistema. Ahora debes:

  1. Ir a Flow.com → Link de pago
  2. Generar un nuevo link con estos datos:
    • Monto: $0
    • Descripción: Informe
    • Email: cliente@example.com
  3. Copiar el link de Flow
  4. Pegar aquí abajo:

📝 Flujo Completo:

  1. Aquí en el dashboard:
    • Selecciona el tipo de informe
    • Ingresa empresa/persona a investigar
    • Completa datos del cliente
    • Haz clic en "Generar Link"
  2. En Flow.com:
    • Abre Flow.com → Link de pago
    • Crea un nuevo link con el monto y descripción que te muestra
    • Copia el link de Flow
  3. Vuelve aquí:
    • Pega el link de Flow en el campo
    • Haz clic en "Guardar Link"
  4. Comparte con cliente: Envía el link por WhatsApp, email, etc.
  5. Automático: Cuando pague → informe generado → email enviado
